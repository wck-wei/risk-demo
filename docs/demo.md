# HTML 前端演示指南

## 打开页面

下载并解压仓库中的 `risk-demo.zip`，用现代浏览器打开 `risk-demo/demo/index.html`。页面和样式、案例数据、脚本应保留在解压后的同一目录。首次打开即可离线使用。

## 推荐讲解顺序

1. 选「授信 → 标准授信」，点「播放流程」。用「暂停播放」或「下一步」停在规则和模型节点，说明两个环节分别检查什么。完成后展示 30,000 的授信额度和 12 期还款期限。
2. 切换到「授信 → 近期逾期」。展示引擎命中拦截规则后直接返回结果，以及模型节点保持未执行状态。再切换到「收入特征补取」，观察模型如何告知引擎缺项，以及引擎如何请特征服务回补一次。
3. 选「下单 → 模型超时」。解释可用额度等规则检查完成后，为什么系统仍要求二次验证。
4. 比较「定价 → 标准定价」和「匹配竞品报价」。查看基础年利率、模型建议和最终报价。标准样例的最终年利率为 15%，演示 APR 为 16.2%。匹配案例的最终年利率为 14.5%。

流程中的高亮表示当前处理模块。点击模块可查看职责或该模块在已播放步骤中的最近一次处理。点击操作记录可以回到对应步骤。切换案例会从头开始。

## 更新案例数据

页面回放 Python 引擎已生成的 10 个案例。要改变案例描述、参数或故障条件，编辑 `demo/generate_cases.py`。下列命令均在项目根目录运行。

```sh
python3 demo/generate_cases.py
python3 demo/generate_cases.py --check
python3 -m unittest discover -s tests -v
```

`--check` 会比对现有 `cases.js` 与本次引擎生成的结果，便于发现展示数据落后于引擎的情况。
