# HTML 前端演示指南

下载并解压 `risk-demo.zip`，在现代浏览器中打开 `risk-demo/demo/index.html`。浏览器从同目录加载样式、案例和脚本，可离线使用。

## 推荐讲解顺序

1. **标准授信**。先点 RCMS 查看当前发布的规则流，再播放。对比引擎为规则查取的数据与 Magic Cube 为模型查取的数据。流程完成后，展示 30,000 的授信额度和 12 期还款期限。
2. **反洗钱名单复核与设备风险验证**。在授信和下单中分别选择这两个案例。展示为何转人工或要求二次验证，并指出模型在线服务尚未执行。
3. **切换规则流版本**。对比下单中的「超过可用额度」与「切换规则流版本」。两笔演示使用同样的输入，规则节点顺序不同，命中分支也不同。
4. **上报后重新计算**。在下单中选择该案例，点击元信息平台查看已上报的合成订单，再观察特征网关的窗口计算及最终验证要求。
5. **收入特征补取与切换模型版本**。选择授信的补取案例，查看 Magic Cube 如何自行填补模型输入。再比较「标准授信」与「切换模型版本」，通过 Magic Cube 卡片查看注册、校验与部署记录。
6. **标准定价与匹配竞品报价**。比较模型建议和最终报价。标准样例年利率 15%，演示 APR 16.2%。竞品匹配样例年利率 14.5%。

节点高亮表示当前处理模块。点击平台可查看配置和发布职责，点击在线模块可查看最近一次处理。操作记录可返回任一已播放步骤。切换案例会从头开始。

## 更新案例数据

页面回放 Python 引擎生成的 15 个案例。要改变案例描述、参数、发布版本或故障条件，编辑 `demo/generate_cases.py`。在项目根目录运行以下命令。

```sh
python3 demo/generate_cases.py
python3 demo/generate_cases.py --check
python3 -m unittest discover -s tests -v
```

`--check` 将提交的案例数据和重新执行引擎得到的结果进行比对。平台配置方法及示例见[三平台与在线决策](platforms.md)。
